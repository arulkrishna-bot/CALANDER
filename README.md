## 🛠️ GitHub-ல் ஏற்றி 2 நிமிடத்தில் APK பெறுவது எப்படி?

1. இந்த ZIP கோப்பை உங்கள் கணினி அல்லது மொபைலில் **Extract (அன்சிப்)** செய்யவும்.
2. உங்கள் GitHub கணக்கில் **புதிய Repository** ஒன்றை உருவாக்கவும் (உதாரணம்: `tamil-3d-calendar`).
3. அன்சிப் செய்த அனைத்து கோப்புகளையும் (`.github`, `index.html`, `package.json`, `capacitor.config.json`) GitHub-ல் பதிவேற்றவும் (Upload / Push).
4. நீங்கள் ஃபைல்களை ஏற்றியவுடன், மேலே உள்ள **"Actions"** tab-க்குச் செல்லுங்கள்.
5. அங்கே **"Build Android APK"** தானாகவே இயங்கத் தொடங்கும் (சுமார் 2 - 3 நிமிடங்கள் எடுக்கும்).
6. பில்ட் முடிந்ததும், அந்த ரன் (Run) மீது கிளிக் செய்தால் கீழ்ப்பகுதியில் **Artifacts** என்ற இடத்தில்:
   👉 **`Tamil-3D-Calendar-v2.5-Debug-APK.zip`**
   என்று இருக்கும். அதைத் தொட்டு உங்கள் மொபைலில் இன்ஸ்டால் செய்து கொள்ளலாம்! 🎉
